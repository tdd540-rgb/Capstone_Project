# Capstone_Project


## Validating Evaluation Metrics for Medical Image Generation on X-ray/CT/MRI Scans
### This repository contains model development notebooks and evaluation results for my MSc Capstone Project. Although the project title covers X-ray, CT and MRI, the experiments in this project focus on 3D brain MRI from the BraTS 2023 Adult Glioma dataset.


## Repository contents
### The repository contains:
#### Jupyter notebooks from different stages of DDPM, Conditional DDPM and Conditional LDM development, including VAE experiments.
#### Earlier versions and later attempts that were not selected for the final comparison.
#### Saved upstream and downstream evaluation results.
